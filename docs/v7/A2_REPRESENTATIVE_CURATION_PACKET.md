## Boundary

This is an **advisory editorial packet**, not a publication decision. It does not change the frozen V7 content-import contract and it does not mark any item `approved` or `published`. The normal Leader/Pastor/Admin moderation path remains authoritative.

Scripture anchors below are discovery/discussion suggestions. They are not claims that every verse is quoted by the source. Before publication, the reviewer must verify any Scripture displayed by BibleQuest for reference accuracy and context.

Theological-fit labels used here:

- `core_fit` — strong direct fit for broadly evangelical discipleship use.
- `core_fit_with_context` — strong historic Christian fit; some sections need historical/doctrinal context.
- `compatible_with_context` — substantial useful Christian material, with tradition/rhetoric/history that should be surfaced.
- `tradition_specific_context` — potentially useful, but requires explicit tradition framing and selective editorial use.
