# BibleQuest V5 localization glossary

This glossary keeps BibleQuest-authored English, Tagalog, and later Cebuano/Bisaya UI terminology consistent. Scripture text is never translated by this mechanism; Scripture must continue to come from approved/licensed Bible sources.

| Key concept | English | Tagalog guidance | Cebuano/Bisaya guidance |
| --- | --- | --- | --- |
| Bible | Bible | Biblia | Biblia |
| Home | Home | Home (retain where most natural in app navigation) | Balay/Home to be reviewed with Cebuano pass |
| Calendar | Calendar | Kalendaryo | Kalendaryo |
| Assignments | Assignments | Mga Gawain | Mga Buluhaton |
| Community | Community | Komunidad | Komunidad |
| Notifications | Notifications | Mga Abiso | Mga Pahibalo |
| Settings | Settings | Mga Setting | Mga Setting |
| Transformation | Transformation | Retain product/ministry feature name unless a reviewed contextual phrase is clearer | Retain product/ministry feature name unless reviewed otherwise |
| Save | Save | I-save | I-save |
| Continue | Continue | Magpatuloy | Padayon |

Rules:

- `en` is the canonical key inventory and deterministic fallback.
- `tl` and later `ceb` reuse the exact same stable keys; no parallel ad-hoc string system.
- Proper nouns and Bible translation names may remain unchanged.
- Prefer natural ministry-appropriate language over literal word-for-word translation.
- Missing locale entries fall back to canonical English and remain test-detectable.
