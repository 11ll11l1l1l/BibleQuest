# BibleQuest

Learn the Bible through games, stories, situational questions, challenges, and reflection.

## Public app

GitHub Pages target: `https://11ll11l1l1l.github.io/BibleQuest/`

## Playable now

- Daily 5
- Quick Play
- Context Mode
- Bible Detective
- Story Adventure
- Timeline Challenge
- Situations & Wisdom
- Deep/open-question polling
- Bible Journey progress
- XP, streaks and achievements
- Offline/PWA support

Progress currently persists locally in the browser. A dedicated Supabase schema blueprint is in `supabase/schema.sql`; accounts, cross-device progress and community polls are the next backend step.

## Content direction

The production content pipeline will favor public-domain/open resources instead of hand-authoring the entire Bible database. See `DATA_SOURCES.md`.

`Study Together` is intentionally reserved as a future module rather than the current product focus.
